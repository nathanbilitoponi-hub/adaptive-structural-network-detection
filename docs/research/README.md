# Research Background

This folder contains research material related to the development of the Adaptive Structural Network Detection engine.

The research started from experiments on cosmic filament detection using SDSS galaxy data.

Dataset used:
- Sloan Digital Sky Survey (SDSS)
- ~50,000 galaxies
- coordinates: RA, DEC, redshift

The pipeline evolved through multiple versions (V1–V10) including:

- filament detection
- backbone extraction
- Monte Carlo statistical tests
- robustness testing
- anomaly detection

The goal of this research is to develop a general structural network extraction engine capable of detecting backbone structures in noisy spatial data.
